# 💕 Are You The One – Tracker
**Staffel 6 · Von Sabrina**

Mitrate-Assistent für Are You The One. Paarungen, Matchboxen, Wahrscheinlichkeiten.

## Starten
```bash
npm install
npm run dev
```

## Daten laden
`perfect-match-s6-fixed.json` unter Daten → Importieren laden.

## Deployment
Auf [vercel.com](https://vercel.com) → New Project → GitHub Repo → Deploy.
